# Raylib-cs

Este repositório reúne testes, com o objetivo de aprendizagem, feito com Raylib-cs.

## Estrutura do repositório

- [Executáveis 8.0/](./Executaveis%208.0/): Executáveis gerados com a versão 8.0 do Raylib-cs.
- [Navinha/](./Navinha/): Projeto de jogo simples inspirado em jogos antigos de nave, sem sprites.
- [Guilherme/](./Guilherme/): Projeto de jogo com câmera side-scroller.
