## Para `.NET 8.0`
**Mudança manual no projeto no `<OutputType>Exe</OutputType>` para `<OutputType>WinExe</OutputType>` para não ficar gerando console**

## Comando usado no VS para geração do executavel
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```
