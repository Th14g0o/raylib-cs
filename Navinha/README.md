# Navinha

**Jogo simples de navinha.**

**A movimentação é da esquerda para direta**
- tecla `A` e `Seta Esquerda` para ir para esquerda
- tecla `S` e `Seta Direita` para ir para esquerda

**Sua nave pode destruir naves inimigas clicando com `Botão Esquerdo do Mouse` ou a tecla `Enter`**

**A cada `2500` pontos `+1` inimigo com `velocidade aleatoria`**
